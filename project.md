We're creating task- and time tracking web app. There are projects that consist of tasks, and user can track time for each task and see how many time they spent for a task or a project.

In the profile they can see and change their name, e-mail, language, theme (dark or light), and motto (custom message).

And there are the reports page, where a user can see a graph with a duration per day for each project.

The main page is the tracker page.
