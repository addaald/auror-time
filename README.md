# Auror Time

**Auror Time is an aesthetic time and task tracker for more intentional work.**

The project is in active development. Its current preview is a local Pomodoro timer for focus sessions—the first building block of Auror Time.

## Current preview: v0.1.2

- Circular focus timer with 15, 25, 45, 60-minute presets and a custom duration.
- Optional task name displayed beneath the timer.
- English and Russian interface.
- Gong sound when a focus session ends.
- Session history saved locally in the browser.

## Run it

Download `Auror Time.html` from the latest release and open it in a modern browser. No installation or server is required.

## Data and privacy

Timer state and session history are stored in the browser on the current device. They are not uploaded or synced to an account. Use the same browser to see the same local history.

Auror Time is one evolving project; the focus timer is its starting point, not a separate app.
